# Catalog explorer

Every dataset netgamut indexes, read from the catalogs bundled with this
release. Search names and descriptions, narrow by source, domain, size or trait
of network, and
open a dataset to see how to load and cite it. As in `netgamut.search()`, a
network that KONECT copies from Netzschleuder or SNAP is listed once, from that
source; a filter option brings KONECT's copies back.

```{raw} html
<div id="netgamut-explorer" data-index="_static/explorer/catalog.json">
  <noscript>The explorer needs JavaScript. <code>netgamut list</code> prints the same catalog.</noscript>
</div>
```
